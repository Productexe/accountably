# Accountably

First web MVP slice for the Accountably accountability product.

## Current milestone
- Responsive web dashboard
- Goals/groups concept (mock data)
- Public commitment scores
- Commitments UI
- Check-in UI
- Needs-you accountability prompt
- Mobile-friendly layout

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
